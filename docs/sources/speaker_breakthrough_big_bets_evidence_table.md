## Reconciliation

The local oracle evidence and the external TSE literature agree on the core point: target speech can
be recoverable from a single-channel mixture, but it usually requires either a target-conditioned
extractor trained for the target domain or a joint speech/speaker model. The local negative results
reject small modular substitutions, not the upper-90 target itself.
